Sample project

PDF purchase agreement to Excel, with a deadline timeline

Problem
Contract details get retyped by hand, and deadlines are counted on a calendar, where a weekend date is easy to miss.
Approach
Extract 15 labeled fields from the PDF (password-protected files supported), write them to Excel, and build a timeline sheet driven by real Excel formulas.
Result
On the sample contract, all 15 of 15 fields are found. Change one date cell and every deadline recalculates; weekend deadlines roll to Monday and are flagged. Missing fields are reported, never silently dropped.

Sample project

Paginated web scraper to clean CSV and Excel

Problem
“Get the data off these pages into a spreadsheet” sounds simple until you hit pagination, failed requests and duplicates.
Approach
Follow the next-page link, retry with backoff on errors and rate limits, wait politely between pages, parse each item, then dedupe and sort.
Result
All 1,000 books from 50 pages of books.toscrape.com (a practice site) in a sorted CSV and a filterable Excel file. Tests run offline and never hit the site.

Sample project

Messy contact list cleanup and dedupe

Problem
Exports from forms and CRMs arrive with ALL CAPS names, broken emails, phones in six formats and dates written every way, so imports and mail merges fail.
Approach
Rule-based fixes for names (O'Brien, McDonald, “van der”), emails, US phones and dates, then drop blank rows and dedupe on the cleaned email.
Result
On the 44-row sample file: 33 emails fixed, 31 phones normalized, 29 dates converted to YYYY-MM-DD, 3 duplicates removed, 40 clean rows out, plus a before/after report. Standard library only.

Sample project

Scheduled API watcher with webhook alerts

Problem
People want to know when a number crosses a line without checking a website all day.
Approach
Poll a free public exchange-rate API, log every reading to CSV, and post one combined alert to a Slack/Discord-style webhook when a JSON rule is triggered. The webhook URL lives in an environment variable, not the code.
Result
Runs once from cron or Task Scheduler, loops on its own, or runs hourly in GitHub Actions. Dry-run mode when no webhook is set. Tests use a fake API and a local mock webhook server.
